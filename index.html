Privacy Policy

Last updated: September 29, 2026

1. Introduction

This Privacy Policy describes how AN Digital Solutions processes information when using its software tools and applications that connect to the eBay API.

The application accesses eBay seller accounts only after explicit authorization by the respective eBay account owner.

2. Data We Access

Depending on the permissions granted through eBay OAuth, the application may access:

  • Seller account information
  • eBay Business Policies
  • Shipping policies
  • Payment policies
  • Return policies
  • Listing and inventory information where required
  • eBay account identifiers
  • OAuth access and refresh tokens required to communicate with the eBay API

The application does not request or store the user's eBay password.

3. Purpose of Processing

The accessed data is used only for functionality requested by the account owner, including:

  • Reading existing eBay Business Policies
  • Creating or transferring Business Policies between authorized eBay seller accounts
  • Managing eBay seller account configuration
  • Managing listings or inventory where explicitly required

The data is not used for advertising, profiling, or marketing purposes.

4. Data Storage

The application is currently used as a local software tool.

eBay API credentials and OAuth tokens may be stored locally and securely for the time necessary to perform the requested operations.

Data obtained from eBay is not sold, rented, or disclosed to third parties for advertising purposes.

5. Data Sharing

Personal data obtained through the eBay API is not sold or shared with unrelated third parties.

Data may only be processed by service providers where technically necessary or where disclosure is required by law.

6. Security

Reasonable technical and organizational measures are used to protect API credentials, OAuth tokens, and data against unauthorized access, loss, misuse, or disclosure.

7. Revoking Access

Users can revoke the application's access to their eBay account through their eBay account settings. After access is revoked, the application can no longer access the respective account using that authorization.

8. Data Deletion

Users may request deletion of personal data processed by the application by contacting us. Data will be deleted unless continued retention is required by applicable law.

9. User Rights

Where applicable under the GDPR, users may have the right to:

  • Request access to their personal data
  • Request correction of inaccurate data
  • Request deletion of their data
  • Request restriction of processing
  • Object to certain processing
  • Request data portability
  • Withdraw consent where processing is based on consent

10. Third-Party Services

The application communicates with eBay through the official eBay API. eBay processes information according to its own Privacy Notice and terms.

If this website is hosted using GitHub Pages, GitHub may process technical information such as IP addresses and server logs according to GitHub's own privacy policies.

11. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. The latest version will always be published at this URL.
